# FLOWI marketing — doimiy eslatmalar
- Foydalanuvchi bilan o'zbek tilida gaplash. Faqat `claude/flowi-marketing` branchida ishla; dastur branchiga push qilma.
- Reklamada "7 kun bepul"; dastur UI skrinshotlari ijtimoiy tarmoqda ko'rsatilmaydi; Instagram'ga tasdiqsiz hech narsa joylanmaydi.
- MONTAJ USLUBI: yangi reels/video yasashdan oldin `marketing/style/COLLAGE-STYLE.md` ni o'qi — foydalanuvchi tanlagan "qizil kolaj-esse" uslubi (namuna kadrlari shu papkada).
- 2-USLUB: `marketing/style/STORY-STYLE.md` — "biznes-hikoya" (yorug', kursiv serif, raqamlar, ramka ichiga kirish). Muammo/qo'rquv mavzusi → 1-uslub; natija/o'sish mavzusi → 2-uslub.
- 3-USLUB: `marketing/style/PIXEL-REEL-SPEC.md` — "pixel reel" (6–8 s, odam videosi + pixel shrift, line burst, logo ochilishi; kodda kadrma-kadr). Foydalanuvchi o'z videosini bersa yoki "pixel reel" desa — shu topshiriq bo'yicha ishla.
